Korekt AI for Jira

AI code review insights directly in your Jira issues

Overview

Korekt AI for Jira adds a context panel to your Jira issues that displays AI code review results from linked pull requests. When developers reference a Jira issue key in their branch name or PR title, the review results automatically appear in the Jira issue — giving project managers and team leads visibility into code quality without leaving Jira.

How It Works

  1. Developer creates a PR — The branch name or PR title includes a Jira issue key (e.g., feature/PROJ-123-add-login)
  2. Korekt AI for Bitbucket reviews the PR — The code changes are analyzed and review results are stored, linked to the issue key
  3. Jira panel shows results — When anyone opens the Jira issue, the Korekt AI panel automatically fetches and displays the latest review findings

Note: This app displays review results — it does not perform code reviews itself. Code reviews are performed by Korekt AI for Bitbucket. Both apps should be installed for the full experience.

What the Panel Shows

  • Change intent — Whether the code change is a feature, fix, improvement, maintenance, or operational change
  • Complexity score — A rating of the change's complexity
  • Severity breakdown — Count of issues found by severity (critical, high, medium, low)
  • Ticket compliance — A percentage score indicating how well the code changes satisfy the Jira ticket requirements
  • Change summary — A brief AI-generated description of what the code changes do
  • Review date — When the most recent review was performed

If no pull requests have been reviewed for a given issue, the panel displays “No code reviews found for this issue.”

Installation

  1. Install Korekt AI for Jira from the Atlassian Marketplace
  2. Select the Jira site where you want to enable review insights
  3. The app automatically links to your Korekt account if you have Korekt AI for Bitbucket installed in the same Atlassian organization

No additional configuration is required. The panel appears automatically on all Jira issues.

Testing

To verify the app is working after installation:

  1. Ensure Korekt AI for Bitbucket is also installed in the same Atlassian organization
  2. Create a pull request with a Jira issue key in the branch name (e.g., PROJ-123-my-feature)
  3. Wait for the Bitbucket app to complete its review
  4. Open the corresponding Jira issue — the Korekt AI panel should appear in the issue context showing the review results

Prerequisites

This app works best when paired with Korekt AI for Bitbucket. The Bitbucket app performs the code reviews and stores the results. The Jira app retrieves and displays those results in the issue panel.

Both apps should be installed within the same Atlassian organization for automatic account linking.

Privacy & Security

The Jira app only sends the Jira issue key to the Korekt backend to look up existing review results. No Jira issue content, descriptions, or code is sent from this app.

All communication uses Forge Invocation Tokens (FIT) — cryptographically signed JWTs issued by Atlassian. No API keys or shared secrets are used.

For full details, see our Privacy Policy and Security Policy.
